# Calculadora
Uma calculadora em Python. 

O python_script.sh executa o calculadora.py. Para utilizá-lo use o comando ./python_script.sh no terminal. 

O script calculadora.py realiza operações básicas de matemática entre dois valores baseadas no input do usuário. 


# Calculator

A calculator in Python.

The python_script.sh runs calculadora.py. To use it, run the command ./python_script.sh in the terminal.

The calculadora.py script performs basic mathematical operations between to values based on user input.
